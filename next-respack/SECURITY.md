# Security Policy

Next Respack 的安全策略与加固建议见 [docs/SECURITY.md](docs/SECURITY.md)。

## 报告漏洞

请勿通过公开 Issue 披露安全问题。请私下联系维护者，提供：

- 受影响的版本
- 复现步骤与最小示例
- 影响范围（信息泄露 / 权限提升 / 拒绝服务等）
- 建议修复方向（如有）

我们会在确认后尽快修复并在 CHANGELOG 中记录。

## 范围

- 安装向导与安装锁
- 认证、角色与账户状态
- 资源包上传与 ZIP 校验
- 匿名下载 Token 与 Range 处理
- 存储适配器与迁移
- 后台管理操作与审计日志
